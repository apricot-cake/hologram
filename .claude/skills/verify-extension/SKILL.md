# verify-extension — 拡張の変更を実ブラウザで確かめる

正本は `docs/build.md`「拡張機能の開発・配布」。矛盾があればそちらが勝つ。

## 前提: Chrome が読み込んでいるのは production ビルド

実 Chrome に常時読み込まれているのは**本体ツリーの `extension/.output/chrome-mv3`**（2026-07-26 に dev 読み込みから入れ替え）。検証はビルド成果物で行う＝このリポの E2E（`scripts/e2e-capture-test.cts` ほか）が読むのと同じ物。dev サーバーの生死・接続に依存しない。

## 手順

1. **作業ツリーの `extension/` で `npm run build:ext`**（fresh worktree は先に `npm install`）。
2. **ビルドを検算してから渡す**＝`.output/chrome-mv3/manifest.json` に `content_scripts` があるか・`commands` が揃っているか・変更した識別子がバンドルに実在するか。ここで確かめられることをユーザーに確かめさせない。
3. **worktree で作業している場合**: 出力 `.output/chrome-mv3/*` を**本体ツリーの同じフォルダへ上書きコピー**する（Chrome が読むのは本体側のパスだから）。本体ツリーで作業していれば不要。マージ後に本体で `build:ext` を打てば正規の状態へ収束する。
4. **ユーザーへの依頼は1つだけ**＝「`chrome://extensions` で Hologram のリロード（🔄）を1回」。人でないと不可能なのはこれと、ログイン済みアカウントでの操作だけ。それ以外を依頼リストに足さない。
5. 検証項目を渡して結果を聞く。

## Claude から見えないもの（実測 2026-07-26）

- **`chrome://` ページは開けない**（ツールが明示拒否）。**`chrome-extension://` は開けるが読めない**（別拡張のページには JS を差せない）。つまり拡張機能ページのエラー表示・リロードボタン・ショートカット割当画面は全てユーザーの領分。
- 挙動が説明できない時は、当てずっぽうの操作依頼を重ねる前に **`chrome://extensions` のエラー画面のスクショを1枚頼む**。そこにしか出ないエラーがある（dev サーバー接続失敗など）。
- 「押しても何も起きないのが正常」という操作（拡張リロード等）を、成否を観測する手段のないまま依頼して往復しない。

## dev:ext（WXT dev サーバー）の扱い

- **ユーザーが拡張 UI を対話的に触る間だけの道具**。使う間だけ `chrome-mv3-dev` へ読み込み替える（ID は `key` 固定で共通）。
- **Claude は dev サーバーを停止しない・検証目的で起動しない。**開発モードの拡張は manifest に `content_scripts` を持たず、常駐スクリプトを dev サーバー接続経由で実行時登録する＝**サーバーを止めた瞬間、拡張はページに何も注入できなくなる**（2026-07-26 実地被弾＝バッジ・保存ボタンが全ページで消えた）。
- dev サーバーは Node ≥17 で `::1` だけに bind することがあり、Chrome は `localhost` を IPv4 に解決して `ERR_CONNECTION_REFUSED` になる。dev モードを使うなら bind 先を確かめる（`--host` で指定可）。
- 背景実行した wxt はログを一切残さない＝生死はプロセス一覧、接続可否は WebSocket を直接叩いて観測する。

## 罠

- **ビルド出力の grep は正規表現リテラルのエスケープで偽の空振りを起こす**。ソースの `/^\/i\/bookmarks(\/|$)/` はバンドル上も `i\/bookmarks` のまま＝`i/bookmarks` で grep すると 0 件になり「ビルドされていない」と誤読する。識別子（関数名・定数名）で探す。
- **拡張を削除→再追加すると `chrome.storage.local`（設定）とショートカット割当が消える**。リロードでは消えない。読み込みパスの切替（削除を伴う）を提案する時はこの2点を添える。
- manifest に**後から追加したコマンドは、既存インストールにはキーが自動割当されないことがある**＝新ショートカットが効かない時は `chrome://extensions/shortcuts` の確認を頼む（新規読み込みなら自動で付く）。
