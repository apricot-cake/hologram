> [!WARNING]
> **Hologram はまだリリース前で、開発が活発に続いています。**
> ダウンロードできるインストーラはまだなく、動かすにはソースからのビルドが必要です。画面・保存されるデータの形式・以下に書かれた挙動は、それまでのものを壊す形で変わることがあります。失いたくないものは、必ず自分でバックアップを取ってください。

ウェブで出会ったコンテンツを、本文・作者・元URLまでまるごと保存して、あとから自由に探せる——**あなただけのコンテンツライブラリ**です。

「あれどこで見たっけ」をなくします。気に入ったイラストも、残しておきたいテキストも、ひとつの場所に集めて、整理して、いつでも引き出せます。

いまの Hologram は SNS 投稿の保存がいちばん得意です（X・Bluesky・Misskey・Mastodon・pixiv 対応）。ライブラリ自体は、ウェブのコンテンツ全般を受け入れる設計になっています。

Hologram は**無料・オープンソース**（MIT ライセンス）。ライブラリの実体はあなたのフォルダに並ぶ普通のファイルだけ——アカウント登録なし、サーバーなし、囲い込みなし。

## できること

- **投稿を丸ごと保存** — スクリーンショットだけでなく、本文・作者・投稿日時・いいね数・元URLまで一緒に。だから後から「あの投稿」を必ず見つけられます。
- **自由に整理・検索** — 自分でつけたタグ、本文中のハッシュタグ、プラットフォーム、日付、エンゲージメント、作者で絞り込み。何千件あっても目当てに届きます。
- **イラストも投稿も同じ場所に** — pixiv のイラストから X のテキスト投稿まで、ひとつのライブラリに。画像はグリッドで眺め（正方形のサムネと情報表示は独立に切り替え可）、本文はリストで読む——見たいものに合わせて。
- **すべて手元に** — データはあなたの PC に保存され、画像とメタデータが普通のファイルとして並ぶだけ。サーバーには何も送りません。後から別のツールで開くのも、まるごと移すのも自由です。
- **バックアップ・持ち出し** — ライブラリ全体を ZIP でエクスポート／インポート。別フォルダへの**定期バックアップ（ミラー）**も設定できます。

## 対応プラットフォーム

X (Twitter) ・ Bluesky ・ Misskey ・ Mastodon ・ pixiv

## 使い方

### 1. 保存する（Chrome 拡張）

気になった投稿を見つけたら——

- **画像にマウスを乗せ、隅の保存ボタンを押す** — 画像とともに投稿の本文・作者・元URLも保存します。タイムラインを離れず、ワンクリックで済みます。
- **`Alt+S` を押して投稿をクリック** — スクリーンショットに加えて、本文・作者・投稿日時・エンゲージメントなどの情報もまとめて保存します。投稿の**見た目**まで残せるのはこちらだけです（隅の保存ボタンでは残せません）。
- **画像をドラッグ** — pixiv のイラストなどを、画像そのままで保存できます。

保存したものはデスクトップアプリに自動で集まります（保存先フォルダを見張っているので、新しいキャプチャは一覧にすぐ現れます）。

タイムラインを流し見しているとき、すでに保存した投稿の画像には小さな印がつきます——「これ保存したっけ？」で手が止まりません。判定はこのPCの中だけで行われ、アプリを閉じていても効きます。拡張機能の設定ページでは、この印を常に表示・ホバー時のみ・非表示のいずれかに切り替えられるほか、保存ボタン自体をオフにすることもできます。

### 2. 眺める・読む

左サイドバー上部で**グリッド**と**リスト**を切り替えられます。グリッドでは**「正方形のサムネ」**と**「情報を表示」**をそれぞれ独立にON/OFFできます——正方形のサムネをONにすると均質な格子になり、OFFなら元の比率のまま並びます。情報を表示をONにすると、各セルに作者・抜粋などの情報が付きます。本文を読むならリストが向いています。

カードの画像をクリックすると、スクリーンショットと原寸画像をまとめた**ギャラリー**が開きます。複数画像の投稿は `←` `→` か矢印キーでめくれ、動画もそのまま再生できます。画面上部のツールバーでズーム（− / 表示% / ＋）と**ウィンドウに合わせる ⇄ 原寸**を切り替えられます（`Ctrl+0` / `Ctrl+1`）。ホイールでのズーム、ダブルクリックでの切替も同じように使えます。

### 3. 探す

左サイドバーから絞り込み・並び替えをします。

- **検索** — 本文やユーザー名で検索（表記ゆれやタイプミスも拾うスマート検索）
- **絞り込み** — プラットフォーム／作者／タグ／ハッシュタグ／日付／反応（いいね数など）／フォルダで（複数選択可）
- **並び順** — 新しい順・いいね順・保存日順 など
- **コマンドパレット（`Ctrl+K`）** — 入力してコマンドを実行したり、タグ・作者・フォルダや他のタブへ直接ジャンプできます。`/` を押すと検索欄にカーソルが移ります。

絞り込み中の条件は画面上部にまとまり、**リセット**で一括解除できます。

### 4. 整理する

- **タグ** — カードを右クリック →「タグを編集」。未タグの投稿にまとめてつけたいときは、「タグなし」で絞り込んで検索を保存し、矢印キーで次々移動しながらタグ欄に入力していきます。
- **フォルダ** — 右クリック →「フォルダに追加…」でテーマ別・お気に入り別に。
- **まとめて操作** — カード左上の ○ で複数選択し、タグ付け・フォルダ追加・グループ化・削除を一括で。
- **取り消し（`Ctrl+Z`）** — タグとフォルダの変更を1手ずつ戻せます。一括操作のときは出てくるトーストの「元に戻す」からも。アプリを閉じるまで有効です。戻すのはその操作が実際に変えた分だけ＝元からそのタグを持っていた投稿からタグが消えることはありません。削除はこのスタックには載りません（消した投稿はゴミ箱で待っています）。

### 5. バックアップ・持ち出し

画面左下の**歯車（設定）**から。

- ライブラリ全体を **ZIP** でエクスポート／インポート
- 別フォルダへの**定期バックアップ（ミラー）**
- テーマ（ライト／ダーク）・表示言語の切り替えもここで

## 取得できないとき

本文・作者・日時・エンゲージメントは、それぞれのプラットフォームの API からブラウザが直接取ってきます（Hologram があなたの代わりにログインすることはありません）。そのため、画面にははっきり見えているのに、何も返ってこない投稿があります。

- **X** — 年齢制限付きの投稿と、鍵付きアカウントの投稿。X が投稿情報を返す窓口は匿名の相手に答えるためのもので、あなたの x.com のログイン状態はそこには届きません。
- **Misskey / Mastodon** — フォロワー限定の投稿と、ログインしていない相手への API アクセスを閉じているサーバー。
- **Bluesky / pixiv** — この種の取りこぼしはありません（pixiv はあなた自身のログイン状態で取りに行くので、あなたに見えているものは読み取れます）。

そうなったときにどうなるかは、保存のしかたで変わります。

- **`Alt+S`** — スクリーンショットはそのまま保存され、画面に出ている内容から一部が補われます。画面から読んだ数値は表示どおりの概数で、API から取れる正確な値とは違います。
- **そのほかの保存のしかた** — 指した画像は保存され、投稿の本文・作者などが欠けた状態になります。
- 投稿について何も取得できず、保存できる画像も無いとき（削除済みの投稿、動画の実体をプラットフォームの応答からしか得られない場合）は、**何も保存しません**。空の項目を残さないためです。

どの場合も保存したその場でお知らせするので、情報の欠けた投稿が黙って混ざることはありません。
