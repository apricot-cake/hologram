# Post Snap

[English](README.md) | **日本語**

> Chrome ウェブストア審査待ち。

SNS の投稿を JPEG 画像としてキャプチャし、検索可能な EXIF メタデータを埋め込んで保存する Chrome 拡張機能です。保存した投稿は、内蔵ビューアで閲覧・検索・フィルタ・タグ付け・エクスポートできます。

## 使い方

1. ツールバーの拡張機能アイコンをクリック（または `Alt+S`）
2. 保存したい投稿をクリック
3. 投稿が JPEG としてダウンロードフォルダに保存され、ビューアにも追加されます

`Alt+V`（またはアイコンを右クリック → オプション）でビューアを開き、保存した投稿を閲覧・検索・フィルタ・エクスポートできます。

## 対応プラットフォーム

- X (Twitter)
- Bluesky
- Misskey

## 機能

- 投稿を JPEG 画像として永続保存
- 保存した投稿を本文・ユーザー・日付・エンゲージメント・自分で付けたタグから検索
- ビューア上でタグ付けや一括削除ができる
- ZIP やオフラインで開ける単体 HTML としてまとめてエクスポート

## ファイル構成

```
Downloads/Post Snap/
  images/
    2026-04-04.jpg       <- EXIF メタデータ付き JPEG
    2026-04-04 (1).jpg
```

ダウンロードフォルダに保存される画像はバックアップを兼ねています。拡張機能を削除した後でも、画像ファイルをインポートしてデータを復元できます。

## EXIF メタデータ

投稿のメタデータは EXIF の XPComment フィールドに JSON として保存されます。エクスプローラーのファイルプロパティ（詳細タブ → コメント）から確認できます。

| EXIF フィールド | 内容 |
|---|---|
| XPComment | 投稿 URL、プラットフォーム、本文、ユーザー情報、エンゲージメント、日時を含む JSON |
| DateTimeOriginal | 投稿の公開日時 |
| Software | 拡張機能名、バージョン、ビルドハッシュ |

XPComment JSON の例：
```json
{
  "url": "https://x.com/user/status/123",
  "platform": "x",
  "text": "投稿本文",
  "displayName": "ユーザー名",
  "screenName": "user",
  "userId": "123456",
  "likes": 783,
  "reposts": 72,
  "replies": 4,
  "bookmarks": 128,
  "date": "2026-04-05T12:34:56Z"
}
```

> **注意:** 「撮影日時」にはスクリーンショットを取った日時ではなく **投稿の公開日時** が表示されます。

### EXIF データが失われる場合

以下の操作を行うと EXIF メタデータが失われることがあります：

- 画像編集ソフト（ペイント、Photoshop 等）で編集して保存し直す
- SNS に再アップロードする
- 一部のクラウドストレージサービスによる画像変換
- Windows フォトアプリで編集する

## キーボードショートカット

| ショートカット | 動作 |
|---|---|
| `Alt+S` | キャプチャモードを開始 |
| `Alt+V` | ビューアを開く |

ショートカットは `chrome://extensions/shortcuts`（または `edge://extensions/shortcuts`）で変更できます。
