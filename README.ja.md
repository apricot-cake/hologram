<p align="center"><strong>日本語</strong> ・ <a href="README.md">English</a></p>

ウェブで出会ったコンテンツを、作者・本文・出どころごとまるごと保存して、あとから自由に探せる——**あなただけのコンテンツライブラリ**です。

「あの投稿、どこいったっけ」をなくします。気に入ったイラストも、残しておきたいテキストも、ひとつの場所に集めて、整理して、いつでも引き出せます。

いまの Corpus は SNS 投稿の保存がいちばん得意です（X・Bluesky・Misskey・Mastodon・pixiv 対応）。ライブラリ自体は、ウェブのコンテンツ全般を受け入れる設計になっています。

Corpus は**無料・オープンソース**（MIT ライセンス）。ライブラリの実体はあなたのフォルダに並ぶ普通のファイルだけ——アカウント登録なし、サーバーなし、囲い込みなし。

## できること

- **投稿を丸ごと保存** — スクリーンショットだけでなく、本文・作者・投稿日時・いいね数・元 URL まで一緒に。だから後から「あの投稿」を必ず見つけられます。
- **自由に整理・検索** — 自分でつけたタグ、本文中のハッシュタグ、プラットフォーム、日付、エンゲージメント、作者で絞り込み。何千件あっても目当てに届きます。
- **イラストも投稿も同じ場所に** — pixiv のイラストから X のテキスト投稿まで、ひとつのライブラリに。画像はカード／タイルで眺め、本文はリストで読む——見たいものに合わせて切り替え。
- **すべて手元に** — データはあなたの PC に保存され、画像とメタデータが普通のファイルとして並ぶだけ。サーバーには何も送りません。後から別のツールで開くのも、まるごと移すのも自由です。
- **バックアップ・持ち出し** — ライブラリ全体を ZIP でエクスポート／インポート。別フォルダへの**定期バックアップ（ミラー）**も設定できます。

## 対応プラットフォーム

X (Twitter) ・ Bluesky ・ Misskey ・ Mastodon ・ pixiv

## 使い方

### 1. 保存する（Chrome 拡張）

気になった投稿を見つけたら——

- **`Alt+S` を押して投稿をクリック** — スクリーンショットに加えて、本文・作者・投稿日時・エンゲージメントなどの情報もまとめて保存します。
- **画像をドラッグ** — pixiv のイラストなどを、画像そのままで保存できます。

保存したものはデスクトップアプリに自動で集まります（保存先フォルダを見張っているので、新しいキャプチャは一覧にすぐ現れます）。

### 2. 眺める・読む

左サイドバー上部で **カード／タイル／リスト**の3表示を切り替えられます。イラストを並べて眺めるならタイル、本文を読むならリストが向いています。

カードの画像をクリックすると、スクリーンショットと原寸画像をまとめた**ギャラリー**が開きます。複数画像の投稿は `←` `→` か矢印キーでめくれ、動画もそのまま再生できます。

### 3. 探す

左サイドバーから絞り込み・並び替えをします。

- **検索** — 本文やユーザー名で検索（表記ゆれやタイプミスも拾うスマート検索）
- **絞り込み** — プラットフォーム／作者／タグ／ハッシュタグ／日付／反応（いいね数など）／フォルダで（複数選択可）
- **並び順** — 新しい順・いいね順・保存日順 など

絞り込み中の条件は画面上部にまとまり、**リセット**で一括解除できます。

### 4. 整理する

- **タグ** — カードを右クリック →「タグを編集」。未タグの投稿に次々つけていく「連続タグ付け」もあります。
- **フォルダ** — 右クリック →「フォルダに追加…」でテーマ別・お気に入り別に。
- **クリップ** — カードにマウスを乗せて 📎 で一時トレイに集め、見比べ。
- **まとめて操作** — カード左上の ○ で複数選択し、タグ付け・フォルダ追加・グループ化・削除を一括で。

### 5. バックアップ・持ち出し

画面左下の**歯車（設定）**から。

- ライブラリ全体を **ZIP** でエクスポート／インポート
- 別フォルダへの**定期バックアップ（ミラー）**
- テーマ（ライト／ダーク）・表示言語の切り替えもここで
