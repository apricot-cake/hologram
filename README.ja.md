# Post Snap

[English](README.md) | **日本語**

> Chrome ウェブストア審査待ち。

X / Bluesky / Misskey の投稿をキャプチャして、内蔵ビューアで後から閲覧・検索できる Chrome 拡張機能。

## 使い方

1. ツールバーのアイコンをクリック（または `Alt+S`）
2. 保存したい投稿をクリック
3. JPEG として保存され、ビューアにも追加される

`Alt+V`（またはアイコンを右クリック → オプション）でビューアを開きます。

## デモ

![Demo](docs/demo.gif)

## 対応プラットフォーム

- X (Twitter)
- Bluesky
- Misskey

## できること

- 投稿を JPEG として保存
- 本文・ユーザー・日付・エンゲージメント・タグで検索
- 投稿にタグを付ける、まとめて削除する
- ZIP や単体 HTML としてエクスポート

## 保存先について

キャプチャした画像は `Downloads/Post Snap/` に投稿情報入りの JPEG として書き出されます。ビューアは独自のデータベースを持っていますが、JPEG はバックアップを兼ねていて、拡張機能をアンインストールしたり別のマシンに移ったりしたときに、画像を読み込み直せばデータを戻せます。

## キーボードショートカット

| ショートカット | 動作 |
|---|---|
| `Alt+S` | キャプチャモードを開始 |
| `Alt+V` | ビューアを開く |

ショートカットは `chrome://extensions/shortcuts`（または `edge://extensions/shortcuts`）で変更できます。
