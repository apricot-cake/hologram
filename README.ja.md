# Post Snap

[English](README.md) | **日本語**

> Chrome ウェブストア審査待ち。

SNS の投稿をキャプチャして、内蔵ビューアで後から閲覧・検索・タグ付けできる Chrome 拡張機能です。

## 使い方

1. ツールバーの拡張機能アイコンをクリック（または `Alt+S`）
2. 保存したい投稿をクリック
3. 投稿が JPEG としてダウンロードフォルダに保存され、ビューアにも追加されます

`Alt+V`（またはアイコンを右クリック → オプション）でビューアを開き、保存した投稿を閲覧・検索・フィルタ・エクスポートできます。

## 対応プラットフォーム

- X (Twitter)
- Bluesky
- Misskey

## 機能

- 投稿を JPEG 画像として永続保存
- 保存した投稿を本文・ユーザー・日付・エンゲージメント・自分で付けたタグから検索
- ビューア上でタグ付けや一括削除ができる
- ZIP やオフラインで開ける単体 HTML としてまとめてエクスポート

## データはあなたのもの

保存した投稿はビューアで管理できますが、キャプチャごとに `Downloads/Post Snap/` フォルダにも投稿情報を埋め込んだ JPEG が書き出されます。つまり：

- ブラウザの外にも常にコピーが残る
- 拡張機能をアンインストールしても、別のマシンに移っても、画像を読み込み直せばすべて復元できる
- JPEG はどの画像ビューアでも開ける — Post Snap はそれをきれいに見るための入り口にすぎません

## キーボードショートカット

| ショートカット | 動作 |
|---|---|
| `Alt+S` | キャプチャモードを開始 |
| `Alt+V` | ビューアを開く |

ショートカットは `chrome://extensions/shortcuts`（または `edge://extensions/shortcuts`）で変更できます。
