# Hologram の開発版を検証する

検証を始める前に、リポジトリの `docs/開発ガイド.md` と `docs/テスト.md` を読む。このスキルへ手順を複製せず、両文書を正本として扱う。

変更箇所に応じて検証経路を選ぶ。

- デスクトップアプリを自分で確認するときは、既定でサンドボックスを使う。実ライブラリは、フィクスチャで再現しない問題を読む場合か、ユーザーへ確認を依頼する場合だけ使う。
- 拡張機能を確認するときは、開発ビルドの監視を継続したまま、別のターミナルから開発用 Chrome プロファイルを開く。日常用 Chrome に開発ビルドを読み込まない。
- 保存、IPC、Native Messaging、画面操作など、変更した境界に応じた自動検査を `docs/開発ガイド.md` と `docs/テスト.md` から選ぶ。

起動メッセージだけでは成功とみなさない。アプリまたは開発用 Chrome で変更した経路を実際に操作し、期待した結果まで確認する。拡張機能では現在の CDP 接続も確認する。監視処理が終了した場合や開発用プロファイルへ接続できない場合は検証未完了とする。

実ライブラリを使う画面には個人データが含まれる。スクリーンショットやログを外部へ共有しない。テスト用アカウントの認証情報も成果物へ残さない。

自分で実機操作を確認できない場合は、確認できた範囲とユーザーが確認する項目を明示する。実機操作を確認したとは言わない。

変更に必要な自動検査、現在の実行環境、変更経路の実機操作がすべて成功してから完了を報告する。
