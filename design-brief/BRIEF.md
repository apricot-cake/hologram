# Corpus — UI デザインブリーフ（claude.ai/design 用）

このフォルダの PNG と、この説明を claude.ai/design に渡して「見た目をいい感じに」してもらうための資料です。

---

## 1. アプリ概要

**Corpus** は、SNS投稿（X / Bluesky / Misskey / Mastodon）と pixiv のイラストを**画像として保存・閲覧**するデスクトップアプリ（Electron）。ローカルの保存先フォルダに「画像＋メタデータJSON」を貯め、それを検索・フィルタ・整理して眺める“個人アーカイブ／資料ビューア”。日本語UIが主（英語にも対応）。

ユーザーは「気に入った投稿・絵をコレクションして、あとから探したり眺めたりする」のが主目的。**落ち着いて長時間眺められる・探しやすい**のが理想。

## 2. 技術的な制約（重要・デザイン時に意識してほしい）

- **Electron アプリ。実装は単一の `index.html`＋バニラ HTML/CSS/JS**（React や Tailwind などのビルドは無し）。最終的に CSS を手で移植します。
- **DOM構造は大きく変えない前提**で、**配色・余白・角丸・影・タイポグラフィ・状態表現（hover/active/selected）中心**に整えてほしい。要素のID/classはJSが参照しているため、構造の作り変えは避けたい（必要なら別途相談）。
- **日本語テキストが主**。フォントサイズ・行間・字間は日本語が読みやすい設定で。
- 現状は**ライトテーマ**のみ。ダークテーマ案があれば歓迎（任意）。
- ウィンドウ幅は ~1100px 想定。左に固定幅サイドバー（約250px）＋右にコンテンツ。

## 3. 画面とコンポーネント（スクショ対応）

### `01-post-view.png` — 投稿閲覧（カード一覧）
- 左サイドバー: ブランド「Corpus」→ モード切替（**投稿閲覧 / 画像閲覧**）→ タブ（投稿 / ハッシュタグ / ユーザー / 設定）→ 検索ボックス＋検索方式トグル「通常/あいまい」→ 並び替え→ グリッド/リスト切替→ 件数→ フィルタ群（プラットフォーム/投稿タイプ/メディア/日付/エンゲージ/タグ/フォルダ。チップ式、折りたたみ可）。
- 右: 投稿カードのグリッド。各カードに プラットフォームバッジ・作者名・本文/タイトル・エンゲージ（❤️/RT/💬）・投稿日/キャプチャ日・タグチップ。カード右上ホバーで「📁ワンクリックでフォルダ追加」オーバーレイ。
- ※スクショの画像部分は白（ダミー画像）。実際はここに投稿のスクショ画像が入る。

### `03-image-view.png` — 画像閲覧（タイルグリッド）
- 同じ左サイドバー枠だが、画像向けフィルタ（検索/プラットフォーム/並び替え/最低いいね/表示オプション/タイルサイズ ± /タグ/フォルダ）。
- 右: 画像タイルのグリッド。タイル下部に作者名と❤いいね数のオーバーレイ。ホバーで操作（📁追加・ℹ詳細・↗元投稿・🗑削除）と、左上に選択用の「○」リング。複数選択でまとめてグループ化も可。
- ※白いタイルはダミー。実際は絵/写真のサムネイル。**タイルサイズは可変**（±で拡縮）。

### `05-settings.png` — 設定
- セクション積み重ね: 保存先フォルダ / 言語 / データ（ZIPエクスポート・ZIPから復元・画像を取り込み）/ バックアップ・自動エクスポート（出力先・内容・スケジュール）/ 危険な操作（全削除）。
- カード状のセクション。ラベル＋コントロール＋補足ヒント文の構成。

### `06-folder-modal.png` — フォルダ管理モーダル
- 中央モーダル（背景は薄暗く）。新規フォルダ作成入力＋一覧（名前・件数・★デフォルト・編集/削除アイコン）。

### スクショに写っていない要素（テキストで補足。デザインしてくれると嬉しい）
- **アクティブフィルタバー**: フィルタを1つでも適用すると**サイドバー最下部に固定**で出る帯。適用中フィルタをピル表示＋個別×解除＋「すべて含む/いずれか」(AND/OR)トグル＋「リセット」。
- **画像の詳細ポップアップ（ℹ）**: 中央モーダルで、画像・作者・本文・エンゲージ・日時・タグ・元投稿リンクを表示。原寸ギャラリー（prev/next）も。
- **トースト**: 右下あたりに一時表示する通知（保存しました等）。

## 4. 現状の見た目（参考）
- アクセント色: ブルー `#1d9bf0`（X由来）。背景は明るいグレー/白。角丸・薄い境界線・控えめな影。チップは丸み。
- 全体に“素朴”。**情報量が多い割にメリハリ（視覚的階層）が弱め**、サイドバーのフィルタが詰まって見える、カード/タイルの余白や影が単調、などが気になっている点。

## 5. デザインに期待すること（ここはお好みで上書きしてください）
- 長時間眺めても疲れない、**落ち着いた洗練**。情報の**視覚的階層**を明確に（見出し/値/補助の差）。
- サイドバーのフィルタ群を**すっきり**（密度は保ちつつ整理）。
- カード／タイルの**余白・影・hover**を気持ちよく。グリッドのリズム。
- アクセント1色＋ニュートラル基調で**統一感**。ダークテーマ案もあれば歓迎。
- 日本語が主役なので**和文タイポ**を意識。

## ★ 決定（このセッション）

**方向性 = ① ツール系（Linear/Vercel 風）。テーマは両対応（ライト/ダーク切替）、モノトーン基調＋控えめの差し色。**
参考モック: `refs/1-tool-linear-dark.png`。

### 気に入っている部品（“核”を尊重しつつ、より良く磨いてOK＝凍結しない）
ユーザーは現状の手触りを気に入っているが、**そのまま固定ではなく「良さを尊重した上で、より洗練させて改善してOK」**。色だけでなく余白・階層・状態表現・細部まで磨いて良い。失わないでほしいのは下記の“核（なぜ良いか）”だけ。
- **画像タイル**: 「作者＋❤いいね」を画像に重ねるオーバーレイ感 / 左上○選択 / ホバーで操作が出る（📁・ℹ・↗・🗑）/ ×N / 可変サイズ。グリッドのリズム。
- **チップ（フィルタ/タグ）**: ピル形の軽やかさ、hover/active の反応の気持ちよさ。
- **投稿カード**: 1枚で投稿概要（バッジ/作者/本文/エンゲージ/日時/タグ/📁）が一目で掴める情報設計。
→ これらの核を保ったまま、**遠慮なく洗練・改善して**ほしい（“凍結”ではない）。

### 特に自由に作り変えてOK（執着なし）
- **サイドバー全体**: 現状は**野暮ったい**（フィルタが小さく詰まって窮屈・単調）と感じている。執着なし＝**構造から作り変えてOK**。狙い: すっきり・洗練・余白とリズム、フィルタは密度を保ちつつ整理（アイコン化／グルーピング／既定で折りたたみ／セクション見出しの整理 等は自由）。**DOM変更可**（移植時にJS配線は私が直す）。
  - 関連要望: 上部ナビ（投稿閲覧/画像閲覧＋タブ 投稿/ハッシュタグ/ユーザー/設定）は**スクロール追従**にしたい＆**全モードで常に表示**したい。サイドバー刷新と一緒に設計してよい。

### デザイントークン（目安・①ベース。design 側で微調整OK）
- **Dark**: bg `#0b0c0f` / surface `#0e0f13`・カード `#15161b` / text `#e7e8ec`・muted `#8a8f98`・strong `#f5f6f8` / border `rgba(255,255,255,.07〜.12)` / accent `#7c83ff`（active/selected/focus のみ）
- **Light**: bg `#ffffff`／薄面 `#f6f7f9` / surface `#ffffff`・サイドバー `#f7f8fa` / text `#1c1e22`・muted `#6b7280` / border `rgba(0,0,0,.08)` / accent `#6e6ef7`
- 角丸: チップ 7px / タイル・カード 8〜10px。タイポ: system-ui 基調・本文 13px・和文の行間広め。影は控えめ（ダークは境界線主体、ライトは薄い影）。

## claude.ai/design に貼る用の出だし（例・①確定版）

> Electron 製のデスクトップ「画像/投稿アーカイブビューア」を、Linear/Vercel のような落ち着いたツール系のUIに整えたいです。**テーマは両対応（ライト/ダーク切替）、モノトーン基調＋控えめの差し色（indigo系）**。添付スクショ（投稿カード一覧 / 画像タイルグリッド / 設定 / フォルダ管理モーダル）と `1-tool-linear-dark.png` を参考に、デザインシステム（色・タイポ・スペーシング・状態表現）＋各画面のリスタイル案（HTML/CSSモック）を出してください。
>
> **気に入っている部品（“核”は尊重しつつ、遠慮なく洗練・改善してOK＝凍結ではない）**: 画像タイルの「作者＋いいね」オーバーレイ・○選択・ホバー操作・可変サイズ、チップのピル＋hover/active、投稿カードの情報設計（バッジ/作者/本文/エンゲージ/日時/タグ/📁）。これらの“良さ”を残しつつ、より良くしてください。
>
> **逆に左サイドバーは“野暮ったい”ので、構造から自由に作り変えてOK（むしろ刷新希望）**。フィルタ群（プラットフォーム/投稿タイプ/メディア/日付/エンゲージ/タグ/フォルダ）と、上部ナビ（投稿閲覧/画像閲覧＋タブ：投稿/ハッシュタグ/ユーザー/設定）を、すっきり整理して提案してください。ナビはスクロール追従＆全モードで常に表示できる形が希望。配色・余白・タイポ・角丸・境界・影・hover/active/selected もあわせて。
