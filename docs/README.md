# 開発ドキュメント

このディレクトリには、Hologram を開発・保守するための文書を置いています。作業の目的から次の文書を選んでください。

| 目的 | 文書 |
| --- | --- |
| 開発環境を準備し、アプリや拡張機能を動かす | [ビルド.md](ビルド.md) |
| テストを選び、実行する | [テスト.md](テスト.md) |
| 保存から表示までの処理を追う | [コードの歩き方.md](コードの歩き方.md) |
| コンポーネントの責務やデータの流れを確認する | [全体構成.md](全体構成.md) |
| 表示言語を追加または修正する | [ローカライズ.md](ローカライズ.md) |
| 機能の対象範囲を判断する | [射程.md](射程.md) |
| UI とコードで使う固有の用語を確認する | [用語集.md](用語集.md) |

利用者向けの機能説明は、リポジトリ直下の [README.md](../README.md) を参照してください。プライバシーとライセンスに関する開示は [PRIVACY.md](PRIVACY.md) と [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) にあります。
