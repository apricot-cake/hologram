# Hologram 用語集

この文書では、画面とコードで使う Hologram 固有の用語を対応付けます。一般的な技術用語は、広く使われている名称をそのまま使います。

新しい用語が必要な場合は、実装と画面上の表現をあわせて決めてください。この表だけを編集して名称を決めることはしません。

## 用語

| 画面上の表現 | コード・文書での表現 | 意味 |
| --- | --- | --- |
| ライブラリ | `library` | 保存先フォルダ 1 つ分のコンテンツ、メディア、データベース、関連データのまとまりです。既定の保存先は `~/Hologram/library` です。 |
| — | 原本 / `raw payload` | 投稿の取得時に受け取った応答を加工せず保存したデータです。データベースの `raw_payloads` に保存します。 |
| — | `extractor` | 対応サイトごとに投稿の URL、画面、API からメタデータを読み取るモジュールです。利用者向けには「対応サイト」と表現します。 |
| 正方形のサムネ | `squareThumbs` | 投稿グリッドのサムネイルを正方形に切り抜く表示設定です。 |
| 情報を表示 | `showInfo` | 投稿グリッドに投稿者、本文の抜粋、メタデータを表示する設定です。 |
| メモ | `memo` | 保存したコンテンツに付ける自由記述の注釈です。 |

## 一般名を使うもの

次の領域には独自の製品名を付けません。

| 領域 | 使う表現 | 補足 |
| --- | --- | --- |
| 保存データに添える JSON ファイル | サイドカー / `sidecar` | 完全形式の書き出しやゴミ箱内のデータで使います。通常のライブラリではメタデータを SQLite に保存します。 |
| 拡張機能とローカル保存をつなぐプログラム | Native Messaging ブリッジ / `bridge` | `native-host/` に実装します。 |
| 絞り込みの仕組み | 検索 / `search`、ファセット / `facet` | 画面の文脈に応じて、利用者に分かる表現を選びます。 |
| 元の比率で並べる投稿一覧 | グリッド | 「正方形のサムネ」を無効にした状態です。 |
