# 0009. 選択中の操作は底部中央のフローティングバーに置く

- 状態: 採用（2026-07-13 決定・2026-07-19 実装）
- 関連: #154

## 決定

上部に固定していた選択バーを廃し、**選択が1件以上あるときだけ現れる底部中央のフローティングカプセル**にする（件数＋すべて選択・タグ・フォルダ・グループ・削除・解除）。

アンカーは Google フォトと Linear。

## 影響

- 旧 `#selectionBar` のコンテナ・`data-act` 契約・委譲ディスパッチャを全廃し、各ボタンはオーケストレータの export を直接呼ぶ。
- **配置はコンテンツ列の中に絶対配置**＝広い幅ではインスペクタが隣に並ぶので自動で避けられ、狭い幅（1280px 未満）ではインスペクタが覆いかぶさるため、開いている時だけ右に 320px を予約する。
- **ラベルは幅で切り替える**＝広いときは「タグを追加／フォルダに追加／投稿を削除」、狭くてインスペクタが開いているときは「タグ／フォルダ／削除」。読み上げ用のラベルは常に長い方を使う。

## 却下した案

**アイコンだけのバー**（初版）。何のボタンか分からないため、文字を常に出す形へ変えた。幅が足りないときもアイコンだけには退避させない（✕だけは例外）。
