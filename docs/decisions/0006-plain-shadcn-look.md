# 0006. 素の shadcn ルックを採る

- 状態: 採用（2026-07-13 決定・2026-07-14 に main へ本流化）
- 関連: [0004](0004-own-styling-headless-behaviour.md) を置き換え / #154 / #153

## 背景

素人の自前デザインと、標準に倒し切った設計を比べる目的で全面再設計に着手した。念頭に置いたのは「初めから shadcn で設計していたらどうなっていたか」。

## 決定

**ガラス調の再現はしない＝素の shadcn ルック**（Nova プリセット・Geist フォント）。基盤は **Base UI**（shadcn CLI 現行の新規既定が base-nova であるため。Radix は保守が停滞している）。

標準の内側で裁量が効く部分は、リッチ・モダン・洗練側に倒す（ナビにアイコン、Card グルーピング、AlertDialog 等、作例上位の型）。

## 影響

- [0004](0004-own-styling-headless-behaviour.md)「見た目は自前」は前提ごと失効。
- 旧 `app/renderer/` にはガラス質感由来の記述が残っているが、この層は #3（`window.corpusXxx` 全廃・`viewer.ts` 解体）で解体される。新層 `app/islands/` には無い。

## 却下した案

ガラス質感を新しい基盤の上で再現する案。標準に倒し切った姿を見るという目的そのものと衝突するため。
