# 0003. 自前で持つものと委ねるものの線引き

- 状態: 採用
- 関連: [0002](0002-dependency-adoption-criteria.md)

## 決定

**このプロダクトの価値そのものは自前で持つ**＝各サイトの API 正規化、日本語のあいまい検索、フィルタ、グルーピング、ファイルを真実源とする設計。

**誰が書いても同じになる基盤はライブラリへ委ねる**＝仮想スクロール、ポップオーバーの位置決め、フォーカス管理、アクセシビリティ。ただし委ねるのは痛みが出た時点（[0002](0002-dependency-adoption-criteria.md)）。

判断基準は「手書きの面倒が減るか」の一点。
