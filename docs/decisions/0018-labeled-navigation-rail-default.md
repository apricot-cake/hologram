# 0018. 左サイドバーの既定をラベル付きナビゲーションレールにする

- 状態: 採用（2026-07-31・2026-08-03 #183 で固定行き先を6つに追記）
- 関連: #678／[ADR 0007](0007-horizontal-tabs-not-vertical.md) の「サイドバーがスカスカは非問題」節を置き換える（双方向リンク：同節に本 ADR への前方リンクを追記済み）／#183（疑似タイムラインビュー）がタイムラインをレールの6番目の固定行き先として追加

## 背景

サイドバー左カラムは既定で展開状態（256px）のまま起動し、フォルダ・保存した検索・投稿者フォルダの3グループが空か数件のまま長期間残ることが多い。ADR 0007 はこれを「非問題」と判定していたが、その根拠3点（使うほど育つ／既定の種を置く／薄い時は自動で畳む）はいずれも成立しなかった：既定の種は未実装のまま経過し、自動畳みも未実装、「使うほど育つ」は前提が崩れている——フォルダはタグ主軸の設計下で構造的に手作業でしか増えず、Hologram の保存フロー自体がサイドバーに載る単位を自動生成しない。

実プロダクトのサイドバーを埋める供給源は3種（名前付き階層のコーパス／使用の副産物として増える一覧／メタデータ由来の自動の場所）で、Hologram はいずれも設計判断として閉じている（タグ主軸・グリッド一覧・フィルタバーへの一元化）。これは変える理由のない正しい設計判断であり、結果としてサイドバーの中身は恒久的に薄い。空白の実体は「常設 256px をアプリの最弱の軸（手動フォルダ）に割いている」ことなので、資源側（既定の幅）を中身に合わせて縮めるのが筋。

## 決定

**左サイドバーの既定状態を、展開カラム（256px）から Material Design 3 の Navigation rail 型——アイコン＋短い1語ラベルの畳んだレール（約72px）へ変える。**

- レールに残すのは固定の行き先だけ：投稿・投稿者・タイムライン・ゴミ箱・コマンドパレット・設定（タイムラインは2026-08-03 #183 で追加＝6番目でも M3 の畳み時 3〜7 destinations の範囲内）
- ユーザー生成の一覧（フォルダ・保存した検索・投稿者フォルダ）は展開時のみ表示し、レールでは隠す
- 展開⇄レールのトグル（ボタン・Ctrl+B）と状態の永続化は現行維持——変えたのは初期値と「レールに何を残すか」だけ
- **アイコンのみのレールは採らない**：「設定アイコンとかは見ただけで分かるけど、ビューアイコンのグリッドや人マークって伝わりづらい」（#678 起票理由）——想定ユーザーは SNS の一般利用者で、行き先の発見性はホバー無しで保たれなければならない
- フッターのミラー状態表示（自動バックアップの同期状況）はレール時は隠し、展開時のみ表示する。レールの守備範囲を固定の行き先5つに絞ったことと対にした判断——状態表示は行き先ではなく、72px でもラベル無しの状態表示は本決定自身が禁じるアイコンのみの表示になってしまうため

## 標準

- Material Design 3「Navigation rail」——畳んだ状態が既定・各項目はアイコン＋1語ラベル（ラベル必須）・畳み時 3〜7 destinations（https://m3.material.io/components/navigation-rail/guidelines）
- 身近な実例：YouTube の畳んだ左端（アイコン＋小ラベル）、Claude Desktop の左サイドバー（既定は畳み状態）
- レールに固定の行き先だけを残すのは定型：VS Code のアクティビティバーはユーザーのファイル・フォルダをアイコン化しない。Discord のサーバーレールは各項目が固有アバター画像を持つから成立する例外で、同一アイコンの反復（フォルダ）には移植できない

## 却下した案

- **縦タブ**: ADR 0007 の却下を維持。タブは作業台（閉じたら行が消える）で一覧が育たず、サイドバーを埋める供給源にならない——本決定の診断が却下を補強する
- **サイドバー廃止**: 同ジャンル（DAM・SNS クライアント）に左ナビ不在の前例が見当たらない（確認範囲：Eagle / Lightroom / digiKam / Calibre / X / Bluesky）。固定の行き先の置き場も別途発明することになる
- **既定の種（すべて・未分類・タグなし等）の追加**: 「タグなし」は既にフィルタのタグファセット値として実装済みで、足しても2クリック→1クリックの近道にしかならない。空白を埋める理由で足すのは本末転倒
- **タグ一覧のサイドバー掲載**: IA 背骨（サイドバー＝場所／述語＝フィルタバー）と衝突する
- **現状維持（展開 256px のまま容認）**: 空白の実体は恒久的な資源配分の不釣り合いで、上記診断により非問題ではなくなった

## 実装

`app/src/renderer/src/components/ui/sidebar.tsx`（shadcn fork）の `SIDEBAR_WIDTH_ICON` とラベル付きレール化、`app/src/renderer/src/shell/LeftSidebar.tsx` のユーザー生成グループ非表示化、`app/src/renderer/src/services/sidebar-pref.ts` の既定値。
