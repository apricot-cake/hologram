# 0004. 見た目は自前・挙動はヘッドレス

- 状態: **置き換え**（[0006](0006-plain-shadcn-look.md) へ・2026-07-13）
- 関連: [0003](0003-build-vs-borrow-boundary.md)

## 決定（当時）

スタイル付きのコンポーネントキットは採らない。ガラス質感は自前 CSS で持ち、挙動だけヘッドレス部品（shadcn / Base UI）に委ねる。ヘッドレス化は目的でなく道具なので、動いている手書き実装を先回りで置き換えることはしない。

## なぜ置き換わったか

全面再設計で「素の shadcn ルックを採る＝ガラス質感は再現しない」が確定した（[0006](0006-plain-shadcn-look.md)）。見た目を自前で持つ前提そのものが無くなったため、この決定は成り立たない。

**残っている「動いている手書き実装を先回りで置き換えない」の部分は [0005](0005-no-visual-change-during-migration.md) と [0002](0002-dependency-adoption-criteria.md) が引き継ぐ。**
