# 0005. 移行作業では見た目を意図的に変えない

- 状態: 採用

## 決定

移行（React 化・TypeScript 化などの作り替え）では DOM も CSS もそのままにし、見た目を変えない。**見た目が変わらないこと自体が「移行で壊していない」の検証を兼ねる。**

命名の整理や共有部品の切り出しのように判断が要る変更は、移行とは別のステップに分ける。

## 影響

移行の正しさを見た目の同一性で機械的に判定できる（ビルド出力のハッシュ比較や画面の比較）。代わりに、移行のついでに気付いた改善は別ステップへ回すことになる。

## 適用範囲

全面再設計（[0006](0006-plain-shadcn-look.md)）は移行ではなく作り直しなので、この決定の対象外＝見た目が変わらなければむしろ疑う。
