# 0008. 検索モードの切替を廃し、単一のスマート検索にする

- 状態: 採用（2026-07-13 決定・2026-07-18 実装）
- 関連: #154

## 背景

検索に「ぴったり／おおまか」の切替セグメントがあり、選択は `searchMode` として永続していた。

## 決定

**モード機構を全廃し、常にあいまい（loose）マッチャー1本にする。**

## 理由

検索モードをユーザーに選ばせる標準が無い。GitHub や Linear のような検索の作り込まれた製品は、モードを切り替えさせずに単一の入力で賢く解釈する。切替を出すのは自己流だった。

## 影響

- `search.ts` はクエリのコンパイルだけに縮退（モードの取得・設定・適用・購読と `searchMode` 設定を全廃）。
- クエリ木の text 葉が持っていた葉ごとのモードを撤去（URL 形クエリの完全一致経路は維持）。
- `SearchModeSeg` 島とその設定復元だけが残っていたシェルを削除。
- README とストア掲載文の「あいまい検索も選べる」という説明を更新。

## 既知の欠落

**検索語の除外（「〜以外」）は新しい UI に入口が無い。** 旧チップの右クリック「除くへ移す」は退場した。Linear も GitHub も同じく持たないため、現状は欠落でなく仕様として整理している。
