# タググループ

タググループは、タグを一階層で整理するための名前付きの集合です。タグは一つのグループにだけ所属できます。所属先のないタグは未分類として表示します。グループの名前と用途は利用者が決めます。

タグの絞り込み画面では、グループと所属するタグを分けて表示します。タグ管理画面では、グループの追加、改名、削除と、タグの所属変更を行えます。グループを削除すると所属タグは未分類になりますが、投稿や投稿者に付けたタグは残ります。

DB では、タグの所属先を `tags.groupId`、グループ名を `store_state` の `tagGroupLabels` に保存します。空のグループも保持します。検索では投稿や投稿者に直接付けたタグを照合します。書庫には `tag-groups.json` としてタグ名を基準にした所属情報とグループ名を保存し、別のライブラリへ移した場合も所属を復元します。
