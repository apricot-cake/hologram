# タググループ

タググループは、タグを一階層にまとめるための名前付きの集合。タグは一つのグループに所属でき、所属先のないタグは未分類として表示する。グループの名前と用途は利用者が決める。

タグの絞り込み画面では左側にグループ、右側に所属するタグを表示する。タグ管理画面でグループの追加・改名・削除と、タグの所属変更を行う。グループを削除すると所属タグは未分類になり、投稿や投稿者に付けたタグは残る。

DBではタグの所属先を tags.groupId、グループ名を store_state の tagGroupLabels に保存する。空グループも保持する。検索は直接付けたタグを照合する。書庫では tag-groups.json に名前を基準とする所属情報とグループ名を保存し、別のライブラリへ移した場合も所属を再現する。
