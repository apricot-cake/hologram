# ガラス（フロスト／レンズ）

> Corpus デザイン言語のガラス材質システム。[DESIGN.md](../DESIGN.md)「ビジュアル言語」から分離（2026-06-21・本体の肥大化を抑えるため。要約と入口は DESIGN.md に残置）。

**基準は面の分類＝「浮遊面」か「接地面」か**（旧「一時面だけ」を一般化。2026-06-14 改訂）。根拠は Fluent（Acrylic=浮く面、Mica=接地面）と Apple HIG（マテリアル＝下をコンテンツが流れる面）。

- **浮遊面（画面の上に浮く面）はすべてガラス可**: ポップ／右クリックメニュー／フライアウト／日付・エンゲージポップ／モーダル／トースト／sticky アクティブバー／スライドオーバー時インスペクタ／ライトボックス暗幕／カードのホバーボタン／プルダウン／最上部に戻るボタン。**背後にコンテンツが流れていれば最も映えるが、流れていなくても（単色 Mica の上でも）ガラスは使ってよい**＝半透明素材の質感として可。
- **接地面（レイアウトに固定される面）は Mica 材質**: サイドバー・カード・インライン時インスペクタ。下が単色でぼかす対象が無く「濁ったグレー」になる＋常時GPU負荷のため、ガラス（=ぼかし）でなく Mica（①薄い縦グラデ＝上端 `color-mix` 6%明・下端4%暗 ②微細ノイズ＝SVG `feTurbulence` data-URI・alpha 4.5% ③上端1pxハイライト）で質感を出す。サイドバーが実装例。**ただし接地面でも「動き/選択の瞬間」だけガラス化は可**（Apple Liquid Glass＝ガラスは静止塗りでなく*インタラクションで現れるレンズ*。表示モード切替トグル等は静止時 Mica・ホバー/選択モーションにだけガラス）。

**ガラス材質システム＝「背後に何があるか」で3層を選ぶ**（`index.html` 末尾にユーティリティ層として定義＝`.fold-menu` 等のコンポーネント規則に後勝ち。ホストは自分で `position` を指定＝`::before` スペキュラのアンカー）。共通＝明るいリム＋斜めスペキュラ(`::before`)。
- **A `.glass-lens`（背後＝リッチなコンテンツ／カードの上）**: 高透過(surface 14%)＋薄ブラー(8px)＝**読み抜ける**。透過率の下限なし。**テキスト密なホストは材質を厚く**（Apple も dense text は ultraThin を使わない＝`.kb-hint-pop.glass-lens` は 42%）。実装例＝ショートカット一覧ポップ。
- **B `.glass-frost`（背後＝低コントラスト/低情報／プルダウンがサイドバーの上）**: 中不透明(55%)＋強ブラー(18px)＝**ブラーで霜を自前で作る**ので busy な背景に依存しない。実装例＝カスタムプルダウン `.cs-pop`。
- **C `.glass-relief`（背後＝何もない／トグルが平らな Mica の上）**: **内部に焼き込んだ上明→下暗グラデ**（＝背景が無くても屈折感を出す）＋共有スペキュラ＋明るいリム。backdrop-filter はほぼ効かない前提。実装例＝表示モード切替トグル `.view-toggle`。
  - **ライトの凸ガラスビーズ（C の描き方・2026-06-16 確定）**: 白い面では明るいハイライト/スペキュラが消え、焼き込みグラデだけだと「白い塗り＝プラスチック」。代わりに**凸レンズのビーズ**として描く＝①**中央クリア**（半透明＋frost ブラーで下地の溝グレーが透ける）②**全周の明るいリム**＝縁感（inset 白1px＋内側ブルーム）③**上部中央のドーム反射**（`::before` を中央寄せ radial に＝凸の決め手。光が膨らみの頂点に当たる像）④柔らかい浮き影。中央を透かすのは“縁感”を立てるため。**色は載せない**＝暖寒の斜めグラデ/色収差は左上偏り＆**凹（窪み）に見える**ので却下、縦対称の暖寒も試したが最終は**無色で確定**。**新層は作らず C の描き方として統合**（3層は「背後に何があるか」軸＝平らな背後＝C を*ライトで凸ガラスに見せる*描き方）。実装例＝`.view-toggle .vt-thumb`（**ライトのみ**。ダークは従来の斜め艶を維持＝`[data-theme=dark] .vt-thumb::before`）。凸/凹は2Dの錯覚なので「中央透明＝凹寄り／中央を灯す＝凸」を理解した上で凸を選択。
- **本物の屈折＝SVG変位フィルタ `#glassRefract`（2026-06-16）**: **コンテンツの上に浮く面**（A/B＝フライアウト等）は `backdrop-filter: url(#glassRefract)` で背後を**実際に歪ませる**（`feTurbulence`→`feDisplacementMap`＋軽い `feGaussianBlur`）＝CSS の blur が「ぼかすだけ・位置はそのまま」なのに対し、これは背景が**波打って曲がる**本物の屈折。小領域・静的なら廉価PCでも軽い（重いのは大面積/アニメ/スクロールし続ける背後）。適用面＝`.fold-menu`（フライアウト/メニュー）／`.qf-popover`（日付・エンゲージ）／`.inspector`（浮遊時）／`#sbTop`。**除外**＝①設定モーダル（大面積＋暗幕の上＝屈折しても映る中身が無い＋重い→ blur 据え置き）②`.glass-lens`（読み抜け用＝背後を歪ませると読めなくなる）。**歪みは控えめ厳守**（強すぎ＝生成AI感／下のハード制約）。背後が平らな C には効かない（C は上の凸ビーズで対応）。フライアウト行の**ホバーは半透明**（`--sidebar-row-hover`）＝不透明塗りはガラスに浮くため。
- **旧 frosted トークン（`--glass-filter`/`--glass-bg`系）** はバー/トースト等で継続使用（`.qf-popover`/`#ivToast`）。新規はなるべく上の3クラス＋必要なら `#glassRefract` に寄せる。

**ハード制約（実験でも守る＝却下済み）**:
- ガラスを重ねない（glass-on-glass は濁る）。
- 色収差はエッジ局所で控えめに（強すぎは生成AI感で却下）。
- アクセント色のソリッドなブロブをサムネ上に置かない（にじむ。→ `.act-pill` はニュートラル白）。
- 透明の混合は **srgb**（赤と同じ理由）。`prefers-reduced-transparency: reduce` でソリッドに戻すエスケープハッチ必須。

**ガイドライン（推奨・実験で外してよい）**:
- 浮遊面は背後にコンテンツが流れる位置だと最も映える（必須ではない＝単色上でも可）。
- frosted の tint は小文字を重ねる面では 70% 前後を目安に（読みやすさ優先。**旧「70%未満禁止」はハード制約から格下げ**＝lens のように読み抜ける設計なら下回ってよい）。
- backdrop-filter は数を絞る（GPU負荷）。例: カードのホバーボタンは**ホバー中のカードに限定**して有効化（全カード常時レイヤ化は却下）。

**リキッドホバー（`.act-pill`）**: ⚡↔ℹ 間を**ニュートラル白（rgba 255/0.25）**の光の膜が滑って追従（iPadOSポインタ式）。`:has()` 駆動のCSSのみ・JSなし。**ピルはボタンの上層（z2）に重ねる**（下層だとダークガラス越しでスライドが知覚できない＝ユーザー報告済み）。状態色（赤=外す/緑=追加済み）は半透明膜越しでも判読可。`prefers-reduced-motion` ではフェードのみ。
