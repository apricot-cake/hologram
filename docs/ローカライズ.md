# 表示言語を追加する

Hologram はアプリとブラウザ拡張機能の両方で日本語と英語を提供しています。新しい言語は両方に同時に追加してください。アプリだけ、または拡張機能だけに翻訳を追加して出荷しません。

アプリは設定で言語を選べます。`auto` は OS の言語に従います。拡張機能はブラウザの表示言語に従います。

## 既存の翻訳を修正する

翻訳を修正するときは、表示される画面と意図が分かる説明を添えてください。数、日時、固有名詞は対象言語として自然な表現を優先します。

置換用の記号は意味と数を変えずに残します。アプリとページ内 UI では `$1`、Chrome 拡張機能のメッセージでは `$COUNT$` の形式を使います。`messages.json` の `description` と `placeholders` は翻訳の文脈を伝える情報なので、削除や改名をしません。形式は [Chrome のローカライズ仕様](https://developer.chrome.com/docs/extensions/how-to/ui/localization-message-formats)を確認してください。

## 新しい言語を追加する

`<locale>` を追加するロケール名として、次を 1 つの変更で行います。

1. `app/src/renderer/src/services/i18n.ts` の `MESSAGES` に翻訳表を追加します。基準言語の全キーを訳し、ロケールの解決規則と型を更新します。
2. `app/src/renderer/src/settings/sections/Language.tsx` に、現地語で表示する選択肢を追加します。
3. `extension/public/_locales/<locale>/messages.json` を追加します。`en/messages.json` のキー、`description`、`placeholders` を保ち、`message` を翻訳します。
4. `extension/utils/i18n.ts` に、投稿ページ上の保存 UI 用の翻訳表を追加します。
5. `extension/utils/locale.ts` を更新します。実際に表示する言語と `lang` 属性を一致させてください。これは [WCAG 2.2 SC 3.1.2](https://www.w3.org/TR/WCAG22/#language-of-parts) に従い、支援技術が表示言語を判定できるようにするためです。
6. 翻訳の完全性を検査するテストを新しい言語まで広げます。固定の言語一覧を残さず、追加した言語が基準言語と同じキーと置換記号を持つことを確認してください。

ロケール名とフォールバック規則は [Chrome i18n API](https://developer.chrome.com/docs/extensions/reference/api/i18n) に従います。

## 確認する

次を実行します。

```powershell
npm run check
npm run build:ext
```

続けて、アプリの設定、OS の言語を使う `auto`、ブラウザの表示言語で、それぞれの画面が意図した言語になることを確認してください。機械翻訳だけで行ったローカライズは取り込みません。
