# 表示言語を保守する

Hologram は、アプリと Chrome 拡張機能の両方で日本語、英語、韓国語、簡体字、繁体字を提供します。この五言語以外は対応範囲に含めません。アプリだけ、または拡張機能だけに翻訳を追加して出荷しません。

アプリは設定で言語を選べます。`auto` は OS の言語に従います。拡張機能はブラウザの表示言語に従います。

## 既存の翻訳を修正する

数、日時、固有名詞は対象言語として自然な表現を優先します。

置換用の記号は意味と数を変えずに残します。アプリとページ内 UI では `$1`、Chrome 拡張機能のメッセージでは `$COUNT$` の形式を使います。`messages.json` の `description` と `placeholders` は翻訳の文脈を伝える情報なので、削除や改名をしません。形式は [Chrome のローカライズ仕様](https://developer.chrome.com/docs/extensions/how-to/ui/localization-message-formats)を確認してください。

## 五言語を揃える

文言を追加または削除するときは、次を 1 つの変更で行います。

1. `app/src/renderer/src/services/i18n.ts` の日本語・英語と、`app/src/renderer/src/services/locales/` の韓国語・簡体字・繁体字を同時に更新します。
2. `extension/public/_locales/{ja,en,ko,zh_CN,zh_TW}/messages.json` を同時に更新します。`description` と `placeholders` を保ち、`message` を翻訳します。
3. `extension/utils/i18n.ts` の五言語を同時に更新します。
4. ロケール解決を変える場合は、アプリと拡張機能の両方を更新します。実際に表示する言語と `lang` 属性を一致させてください。これは [WCAG 2.2 SC 3.1.2](https://www.w3.org/TR/WCAG22/#language-of-parts) に従い、支援技術が表示言語を判定できるようにするためです。
5. 完全性テストで、五言語が基準言語と同じキーと置換記号を持つことを確認します。

ロケール名とフォールバック規則は [Chrome i18n API](https://developer.chrome.com/docs/extensions/reference/api/i18n) に従います。

## 確認する

次を実行します。

```powershell
npm run check:extension
```

続けて、アプリの設定、OS の言語を使う `auto`、ブラウザの表示言語で、それぞれの画面が意図した言語になることを確認してください。
