Save SNS posts as JPEG images with embedded EXIF metadata. Post text is stored in the image file, so you can search saved posts by content directly in Windows Explorer — no special tools needed.

Supports X (Twitter), Bluesky, and Misskey.

HOW IT WORKS
1. Click the extension icon or press Alt+S
2. Click the post you want to save
3. The post is saved as a JPEG with EXIF metadata

WHAT'S CAPTURED
- Post text → Comment field (searchable in Explorer)
- Post URL → Title field
- Display name, screen name, user ID → Tags field
- Post date → Date taken field

SEARCH YOUR SAVED POSTS
Use Windows Explorer's search bar:
- Search by content: コメント:keyword
- Search by user: タグ:@handle
- Filter by date range: 撮影日時:2026/04/01..2026/04/03

PRIVACY
No data is collected or transmitted to any server. Only read-only public API requests are made to Bluesky and Misskey to enrich metadata. All images are saved locally.
