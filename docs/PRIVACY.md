# Hologram プライバシーポリシー

## データの取り扱い

Hologram の開発者は、利用者の個人データを受信、収集、保管しません。Hologram 専用のアカウントやサーバーはありません。保存した画像とメタデータは、利用者が選んだ端末上のフォルダに保存されます。

Hologram は、投稿の情報やメディアを取得するために外部サービスと通信します。通信の種類は次の 3 つです。

| 通信元 | 接続先と目的 |
| --- | --- |
| ブラウザ拡張機能 | 保存する投稿があるプラットフォームから、投稿の詳細を取得します。 |
| 端末上の Hologram | プラットフォームのメディアサーバーから、画像や動画を取得します。 |
| 利用者が開いたリンク | 利用者が指定したサイトを、通常のブラウザで開きます。 |

## 1. ブラウザ拡張機能による投稿情報の取得

本文、作者、日付、反応数などを保存するため、拡張機能は利用者のブラウザから投稿元のプラットフォームへ読み取り専用のリクエストを直接送ります。

- **X (Twitter)**（`cdn.syndication.twimg.com`）: 投稿の公開データを取得します。投稿 ID と、そこから算出したトークンを送ります。
- **Bluesky**（`public.api.bsky.app`）: 作者のハンドルを DID（分散識別子）へ解決し、投稿と公開プロフィールを取得します。ハンドル、投稿の AT-URI、作者の DID を送ります。動画を保存する場合は、メディアを保持する PDS を特定するために DID ドキュメントも取得します。`did:plc:` では `plc.directory`、`did:web:` では DID に記載されたドメインへ DID を送ります。
- **pixiv**（`www.pixiv.net/ajax/illust/…`、`www.pixiv.net/ajax/user/…`）: 作品と作者の詳細を取得します。作品 ID と作者のユーザー ID を送ります。これらのリクエストには、利用者の pixiv セッションクッキーが含まれます。接続先は pixiv に限定されます。ログイン中のアカウントで閲覧できる R-18 やフォロワー限定の作品を保存するために必要です。pixiv の認証情報を他の接続先へ送ることはありません。

その他のサイトでは、表示中のページから schema.org、Open Graph、Dublin Core、Highwire のメタデータを読み取ります。この処理はページ内で完結し、追加のリクエストを送りません。

pixiv へのリクエストを除き、上記のリクエストに認証トークン、クッキー、個人情報は含まれません。すべて投稿元のプラットフォームへ直接送信し、Hologram の中継サーバーは使用しません。

## 2. 画像と動画の取得

拡張機能は投稿のメディア URL を端末上の Hologram へ渡します。ネイティブメッセージングホストまたはデスクトップアプリが、その URL から投稿の画像、動画、作者のアイコンを取得します。既存の保存項目へ作者のアイコンを補う場合も同じ経路を使います。

接続先は、プラットフォームの応答に記載されたメディアサーバーです。たとえば、pixiv の原寸画像は `i.pximg.net`、X の画像は X の画像 CDN、Bluesky のメディアは作者の PDS から取得します。

- クッキーや認証情報は送りません。唯一追加するヘッダーは、pixiv の原寸画像を取得するときの `Referer: https://www.pixiv.net/…` です。pixiv の画像サーバーが要求するために付加しますが、セッションクッキーは含みません。
- `https://` の URL だけを許可します。端末内やローカルネットワークのアドレスは拒否します。リダイレクト後の接続先も同じ規則で検査します。
- ライブラリの内容をリクエストへ含めません。

メディアの取得を除き、デスクトップアプリが自動的に外部へリクエストを送ることはありません。

## 3. 利用者が開くリンク

一部の操作は、URL を通常のブラウザへ渡します。画面を表示しただけでは通信しません。利用者が操作したときだけリンクを開き、端末上のファイルをアップロードすることはありません。

- **投稿や作者のプロフィールを開く**: 保存時に記録したプラットフォーム上の URL を開きます。
- **絞り込み条件でウェブを検索する**: 適用中のキーワード、ハッシュタグ、作者のハンドル、日付を、X、Bluesky、pixiv、Google の検索 URL に含めて開きます。
- **選択した文字でウェブを検索する**: 保存した投稿内で選択した文字を Google の検索 URL に含めて開きます。対象は先頭 1,000 文字までです。

リンク先では、利用者のブラウザが保持するセッションと設定が適用されます。

## 権限

- **activeTab**: 拡張機能を起動したときに、現在のタブへ一時的にアクセスします。
- **scripting**: 投稿を選択する UI と、投稿情報を読み取るスクリプトを現在のページへ挿入します。
- **nativeMessaging**: 保存するデータを端末上の Hologram へ渡し、投稿が保存済みかを問い合わせます。
- **storage**: 表示設定、重複保存の警告設定、最近の保存履歴、診断ログを端末上に保持します。ホストへ接続できなかった場合は、再送に必要な画像 URL とメタデータを一時的な保存キューへ保持します。キューは最大 20 件、合計約 5 MiB で、古い項目から削除します。同期ストレージは使いません。
- **contextMenus**: ページのコンテキストメニューに Hologram の保存操作を追加します。
- **ホスト権限**（`cdn.syndication.twimg.com`、`www.pixiv.net`）: 上記の投稿情報を取得するリクエストを許可します。

## 端末上に保存するデータ

投稿のファイルは、利用者が選んだライブラリの `items/<id>/` に保存します。メタデータは同じライブラリのローカルデータベースに記録します。Hologram のサーバーへ送信することはありません。

ブラウザの拡張機能ストレージには、前節に記載した設定、保存履歴、診断ログ、失敗した保存の再送キューだけを保持します。`chrome.storage.sync` は使用しません。再送キューに入ったデータは端末上にとどまり、送信先はネイティブメッセージングホストだけです。
