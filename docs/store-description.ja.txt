=== 要約（最大132文字） ===

ウェブで出会った投稿や作品を、画像・本文・作者・元URLまで自分のPCに保存して検索できるライブラリに。サーバーへの送信は一切ありません。

=== 詳細説明 ===

本文・作者・元URLまでまるごと集められる、自分だけのコンテンツライブラリ。

Hologram は、SNS で見かけた投稿を「スクリーンショットだけ」ではなく、本文・投稿者・日付・いいね数・元URLまで自分の PC に保存し、検索・タグ付け・整理できるようにするアプリです。「あの投稿どこいった？」をなくします。

データはすべて手元に
- 保存先はあなたが選んだローカルフォルダ。当方のサーバーへのデータ収集・送信は一切ありません。
- 画像とメタデータは普通のファイルとして並んで保存されます。他のツールで開く・バックアップする・ライブラリごと移動する——すべて自由です。
- 投稿やアカウントがネット上から見られなくなっても、ライブラリは手元に残ります。
- ライブラリ全体の ZIP エクスポート/インポート、別フォルダへの定期バックアップ（ミラー）にも対応。

保存のしかた
1. 画像にマウスを乗せ、隅の保存ボタンを押す → 画像とともに本文・投稿者・元URLを保存します。
2. Alt+S（または拡張アイコンをクリック）→ 投稿をクリック。見た目のスクリーンショットに加えて、本文・投稿者・日付・エンゲージメントごと保存されます。
3. 画像をドラッグすれば、イラストを画像ファイルそのものとして保存できます。
4. 保存したものはデスクトップアプリに自動で集まります。

あとから見つける
- 本文・ユーザー名で検索（表記ゆれ・タイプミスも拾うスマート検索）
- プラットフォーム/投稿者/タグ/ハッシュタグ/日付/エンゲージメント/フォルダで自由に絞り込み
- 新しい順・いいね順・保存日順などで並べ替え
- グリッド／リストの表示切替（グリッドは「正方形のサムネ」と「情報を表示」を別々に切り替え）、スクリーンショットと元解像度画像をまとめたギャラリー表示

整理する
- タグ付け（「タグなし」で絞り込めば、矢印キーで次の投稿へ移りながら次々に付けられます）
- テーマ別・お気に入りのフォルダ分け
- 複数選択してまとめてタグ付け・フォルダ分け・グループ化・削除

対応プラットフォーム
X (Twitter)／Bluesky／Misskey／Mastodon／pixiv

取得できないとき
X の年齢制限付き投稿・鍵付きアカウントの投稿、Misskey / Mastodon のフォロワー限定投稿などは、プラットフォームが投稿情報を返さないため、画像は保存できても本文・作者などが欠けることがあります（Alt+S での保存なら、画面に出ている内容から一部を補います）。欠けたときは保存したその場でお知らせします。削除済みの投稿は保存できません。

動作に必要なもの
保存・閲覧には Hologram デスクトップアプリ（Windows・無料・オープンソース）が必要です。先にアプリをインストールしてから、この拡張を追加してください。

プライバシー
当方のサーバーへのデータ収集・送信は一切ありません。メタデータ取得のため、閲覧中のプラットフォームへの読み取り専用リクエストがブラウザから直接行われます（X の syndication API・Bluesky・Misskey・Mastodon・pixiv。pixiv はあなた自身のログインセッションを使用します。詳細はプライバシーポリシーへ）。保存はすべて、あなたが選んだローカルフォルダに行われます。
