=== 要約（最大132文字） ===

ウェブで見つけた投稿や作品を、画像・本文・投稿者・元 URL とともに PC へ保存します。保存後はライブラリで検索できます。Hologram のサーバーへは送信しません。

=== 詳細説明 ===

保存した投稿や作品を、あとから探せるライブラリ。

Hologram は、SNS で見つけた投稿を PC に保存するアプリです。スクリーンショットだけでなく、本文、投稿者、日付、いいね数、元 URL も保存します。保存後は検索、タグ付け、整理ができます。

データはすべて手元に
- 保存先は利用者が選んだローカルフォルダです。Hologram のサーバーへデータを収集・送信しません。
- 画像とメタデータは通常のファイルとして保存します。他のツールで開く、バックアップする、ライブラリごと移動することもできます。
- 投稿やアカウントがネット上で見られなくなっても、保存したライブラリは残ります。
- ライブラリ全体を ZIP でエクスポート・インポートできます。別フォルダへの定期バックアップにも対応します。

保存のしかた
1. 画像にマウスを重ね、隅の保存ボタンを押します。画像、本文、投稿者、元 URL を保存します。
2. Alt+S を押すか拡張機能のアイコンをクリックし、投稿をクリックします。スクリーンショット、本文、投稿者、日付、反応を保存します。
3. 画像をドラッグすると、画像ファイルとして保存します。
4. 保存した内容はデスクトップアプリへ自動で追加します。

あとから見つける
- 本文とユーザー名を検索。表記ゆれとタイプミスも検索対象です。
- プラットフォーム、投稿者、タグ、ハッシュタグ、日付、反応、フォルダで絞り込み。
- 新しい順、いいね順、保存日順などで並べ替え。
- グリッドとリストを切り替え。グリッドでは「正方形のサムネ」と「情報を表示」を別々に切り替えます。スクリーンショットと元解像度画像はギャラリーでまとめて表示します。

整理する
- タグ付け。「タグなし」で絞り込むと、矢印キーで次の投稿へ移動しながらタグを付けられます。
- テーマや用途ごとのフォルダ分け。
- 複数選択して、タグ付け、フォルダ分け、グループ化、削除をまとめて実行。

対応プラットフォーム
X (Twitter)／Bluesky／Misskey／Mastodon／pixiv

取得できないとき
X の年齢制限付き投稿と鍵付きアカウントの投稿、Misskey と Mastodon のフォロワー限定投稿などでは、プラットフォームが投稿情報を返さないことがあります。画像を保存できても、本文や投稿者が欠ける場合があります。Alt+S で保存すると、画面に表示中の内容から一部を補います。情報が欠けたときは保存時に表示します。削除済みの投稿は保存できません。

動作に必要なもの
保存と閲覧には、Windows 向けの無料オープンソースソフトウェア Hologram デスクトップアプリが必要です。先にアプリをインストールしてから、この拡張機能を追加してください。

プライバシー
Hologram のサーバーへデータを収集・送信しません。メタデータを取得するため、ブラウザが閲覧中のプラットフォームへ読み取り専用リクエストを直接送ります。対象は X の syndication API、Bluesky、Misskey、Mastodon、pixiv です。pixiv では利用者のログインセッションを使います。保存先は利用者が選んだローカルフォルダです。詳しくはプライバシーポリシーを確認してください。
