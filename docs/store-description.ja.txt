=== 要約（最大132文字） ===

ウェブで見つけた投稿や作品を、画像・本文・投稿者・元 URL とともに PC へ保存します。保存後はライブラリで検索できます。Hologram のサーバーへは送信しません。

=== 詳細説明 ===

保存した投稿や作品を、あとから探せるライブラリ。

Hologram は、ウェブで見つけた投稿や作品を PC に保存するアプリです。投稿の原寸画像や動画とともに、本文、投稿者、日付、反応数、元 URL を保存します。保存後は検索、タグ付け、整理ができます。

データはすべて手元に
- 保存先は利用者が選んだローカルフォルダです。Hologram のサーバーへデータを収集・送信しません。
- 画像とメタデータは通常のファイルとして保存します。他のツールで開く、バックアップする、ライブラリごと移動することもできます。
- 投稿やアカウントがネット上で見られなくなっても、保存したライブラリは残ります。
- ライブラリ全体を ZIP バックアップファイルとして手動で保存できます。一定数の投稿を保存した後に、作成を促す通知も設定できます。

保存のしかた
1. 対応サイトでは投稿にマウスを重ね、左上の保存ボタンを押します。投稿内の画像や動画をまとめて、本文、投稿者、元 URL とともに保存します。画像がない投稿も同じ操作で保存できます。
2. 画像を1枚だけ保存するときは、ブラウザの右クリックメニューから Hologram を選びます。対応サイト以外のウェブ画像にも使えます。
3. 端末上の画像や動画は、デスクトップアプリへドロップするか、ファイル選択から取り込みます。クリップボード内の画像も貼り付けられます。
4. ブラウザで保存した内容はデスクトップアプリへ自動で追加します。

あとから見つける
- 本文とユーザー名を検索。表記ゆれとタイプミスも検索対象です。
- プラットフォーム、投稿者、タグ、ハッシュタグ、日付、反応、フォルダで絞り込み。
- 新しい順、いいね順、保存日順などで並べ替え。
- グリッドとリストを切り替え。グリッドでは「正方形のサムネ」と「情報を表示」を別々に切り替えます。複数画像や動画は投稿単位のギャラリーで表示します。

整理する
- タグ付け。「タグなし」で絞り込むと、矢印キーで次の投稿へ移動しながらタグを付けられます。
- テーマや用途ごとのフォルダ分け。
- 複数選択して、タグ付け、フォルダ分け、グループ化、削除をまとめて実行。

対応プラットフォーム
X (Twitter)／Bluesky／pixiv

取得できないとき
X の年齢制限付き投稿や鍵付きアカウントの投稿などでは、プラットフォームが投稿情報を返さないことがあります。保存ボタンを押した投稿では、画面に表示中の本文や投稿者から一部を補います。情報が欠けたときは保存時に表示します。削除済みの投稿は保存できません。

動作に必要なもの
保存と閲覧には、Windows向けの無料オープンソースソフトウェア Hologram デスクトップアプリが必要です。先にアプリをインストールしてから、この拡張機能を追加してください。

プライバシー
Hologram のサーバーへデータを収集・送信しません。メタデータを取得するため、ブラウザが閲覧中のプラットフォームへ読み取り専用リクエストを直接送ります。対象は X の syndication API、Bluesky、pixiv です。pixiv では利用者のログインセッションを使います。保存先は利用者が選んだローカルフォルダです。詳しくはプライバシーポリシーを確認してください。
