# Corpus

[English](README.en.md) | **日本語**

SNS の投稿と、ドラッグ保存したイラスト／画像を **1 つのアプリ** に集約し、後から閲覧・検索・整理できます。

Corpus は3つの部品でできています。

- **Chrome 拡張機能** — 投稿をクリックして JPEG キャプチャ、または画像をドラッグして保存
- **Native Messaging ブリッジ**（Node）— キャプチャを **あなたが選んだフォルダ** にファイルとして書き出す
- **デスクトップアプリ**（Electron）— 2 つのモードで閲覧・検索・フィルタ・タグ付け・エクスポート

ブラウザストレージも EXIF も使いません。画像・動画とメタデータは普通のファイルとして並んで置かれ、移動もバックアップも自由です（GitHub 等にそのまま放り込めます）。

## 対応プラットフォーム

X (Twitter) / Bluesky / Misskey / Mastodon / **pixiv**

> メタデータは各プラットフォームの安定した公式・公開 API からのみ取得します（DOM スクレイピングはしません）。X は公式 API が無いため `cdn.syndication.twimg.com`（非公式）で代替し、リポスト/ブックマーク/閲覧数は取得できません。

## 2 つの保存方式

- **投稿クリック**（`Alt+S` → 投稿をクリック）: 投稿のスクリーンショット＋元メディアを保存
- **画像ドラッグ**: ドラッグした画像をドロップゾーンに入れると、その画像そのものを保存（スクショ無し）

どちらも投稿 URL から同じメタデータ（本文・作者・日付・エンゲージメント・ハッシュタグ等）を取得します。

## 2 つの閲覧モード（左サイドバーで切替・前回のモードを記憶）

- **投稿閲覧** — 投稿のカード表示（本文・スタッツ・ライトボックス、プラットフォーム/ユーザー/日付/エンゲージメント/タグで絞り込み）。URL を持つ SNS 投稿が対象。
- **画像閲覧** — 正方タイルのグリッド表示（イラスト／画像ライブラリ向け）。検索・プラットフォーム・並び替え（最近保存／更新日／いいね順）・最低いいね数・タグ（グループ表示）で絞り込み。

## できること

- 任意のフォルダに保存（保存先を自分で選べる）
- **タグ／タググループ**で整理・絞り込み
- **画像のグループ化** — 同じ投稿の複数画像を 1 タイルに集約（×N 表示・全画面でページ送り）。投稿単位で解除/再グループ化（永続）、任意画像の手動グループ化、全体の一時展開も可能
- **動画**（mp4 等）・**原寸メディア**の表示（全画面ビューア。動画は既定ミュート）
- ℹ ボタンで詳細をポップアップ表示、↗ で元投稿を開く、🗑 で削除
- ZIP（画像＋メタデータ）／単体 HTML としてエクスポート、HTML から復元（インポート）
- 言語切替（自動／日本語／English）

## セットアップ（開発）

デスクトップアプリはまだパッケージ化していないため、ソースから起動します。

1. `cd app && npm install && npm start` — 初回起動でキャプチャ用ヘルパーを登録します。設定の **保存先フォルダ** で保存場所を選んでください。
2. 拡張を読み込む: `chrome://extensions` → デベロッパーモード ON → **パッケージ化されていない拡張機能を読み込む** → `extension/` フォルダを選択。表示された拡張 ID をアプリの **拡張 ID** 欄に貼り付け。
3. `Alt+S` でキャプチャ（効かない場合は `chrome://extensions/shortcuts` で割り当て）。画像はドロップゾーンへドラッグでも保存できます。

## データ形式（サイドカー）

保存先フォルダに、1 件につき画像とメタデータが並びます。

- `<id>.jpg` … 投稿クリックのスクリーンショット（または保存した画像そのもの）
- `<id>.json` … メタデータ（`platform` / `url` / `text` / `title` / `displayName` / `screenName` / `userId` / `likes`・`reposts`・… / `date` / `capturedAt` / `updatedAt` / `mediaType` / `media[]` / `hashtags[]` / `tags[]` ほか）
- `<id>-media-N.<ext>` … 投稿の原寸メディア（あれば）
- ライブラリ単位のメタ: `tag-groups.json`（タググループ）／`ungrouped.json`・`manual-groups.json`（グループ化設定）

`<captureId>.json` が唯一の真実源です。サーバーには何も送信されません。
