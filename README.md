# Hologram

ウェブで見つけた投稿や作品を、画像・動画、本文、投稿者、元 URL とともに PC へ保存し、あとから探せる Windows 向けライブラリです。

## インストール

準備中です。

## 開発を始める

[開発ガイド.md](docs/開発ガイド.md) を参照してください。
