Hologram は、ウェブで見つけたコンテンツを保存し、あとから探せるライブラリです。本文・投稿者・元 URL も一緒に保存します。

現在は SNS 投稿の保存を中心に扱います。X、Bluesky、Misskey、Mastodon、pixiv に対応しています。ローカルのファイルもライブラリへ追加できます。

Hologram は MIT ライセンスの無料オープンソースソフトウェアです。データは選んだフォルダに通常のファイルとして保存します。アカウント登録や Hologram のサーバーは必要ありません。

## できること

- **投稿を保存** — スクリーンショット、本文、投稿者、投稿日時、いいね数、元 URL を保存します。アンケートの選択肢と票数、投稿者プロフィールも保存します。
- **ローカルファイルを追加** — 画像と動画は通常の投稿と同じように扱います。PDF とアーカイブは収蔵品として、タグ・フォルダ・検索に追加します。
- **整理して検索** — タグ、ハッシュタグ、プラットフォーム、日付、反応、投稿者で絞り込めます。タグの別名で表記ゆれもまとめられます。
- **表示を切り替え** — グリッド、リスト、タイムラインを用途に合わせて選べます。資料は最前面の小窓にも表示できます。
- **データはローカルに保存** — Hologram のサーバーへデータは送信しません。投稿情報の取得と、利用者が選んだ外部操作だけが通信します。
- **バックアップと移行** — ZIP のエクスポートとインポート、別フォルダへの定期バックアップ、複数ライブラリの切り替えに対応します。

## 入れられるもの

- **SNS** — X (Twitter) ・ Bluesky ・ Misskey ・ Mastodon ・ pixiv
- **その他のウェブページ** — ページが公開する schema.org、Open Graph、Dublin Core、Highwire の情報から、タイトル・投稿者・日付を読み取ります。
- **ローカルファイル** — 画像と動画は投稿として追加します。その他のファイルは収蔵品として追加します。

## 使い方

### 1. 保存する

**ブラウザから**（Chrome、Edge、Brave、Vivaldi）

- **画像の隅の保存ボタン** — 画像、本文、投稿者、元 URL を保存します。
- **`Alt+S` を押して投稿をクリック** — スクリーンショット、本文、投稿者、日時、反応を保存します。投稿の表示も保存できる方法です。
- **画像をドラッグ** — pixiv のイラストなどを画像ファイルとして保存します。
- **pixiv のブックマーク一覧をまとめて保存** — 画面に表示中の投稿を一度に保存します。ページ送りは手動です。

拡張機能のツールバーポップアップには、アプリとの接続状態・直近の保存・今日の件数・今見ている投稿の保存ボタンがまとまっています。

**デスクトップから** — ファイルやフォルダをアプリのウィンドウへドラッグ＆ドロップ。

保存したものはデスクトップアプリへ自動で追加されます。保存済みの画像には印を表示します。判定はこの PC の中だけで行います。印と保存ボタンの表示は、拡張機能の設定で変更できます。

### 2. 眺める・読む

表示は **ライブラリ**、**投稿者**、**タイムライン** の3種類です。ライブラリはすべての保存内容を、投稿者は保存元ごとの内容を表示します。タイムラインは投稿を連続して読めます。

ライブラリでは **グリッド** と **リスト** を切り替えられます。グリッドでは「正方形のサムネ」と「情報を表示」を個別に切り替えます。本文を読むときはリスト表示が向いています。

カードの画像をクリックすると、スクリーンショットと原寸画像をまとめた **ギャラリー** を開きます。複数画像は `←`、`→`、矢印キーで切り替えます。動画も再生できます。ズームは上部ツールバー、ホイール、ダブルクリック、`Ctrl+0`、`Ctrl+1` で操作します。

- **ピン留め** — 右クリックから「ピン留めへ送る」を選ぶと、最前面の小窓に資料を表示します。
- **履歴（`Ctrl+H`）** — 開いた場所を日付順に表示します。検索と再表示もできます。

### 3. 探す

左サイドバーから操作します。

- **検索** — 本文とユーザー名を検索します。表記ゆれとタイプミスも検索対象です。
- **絞り込み** — プラットフォーム、投稿者、タグ、ハッシュタグ、日付、反応、フォルダで絞り込みます。複数の条件を選べます。
- **並び順** — 新しい順、いいね順、保存日順などを選べます。
- **コマンドパレット（`Ctrl+K`）** — コマンドを実行し、タグ、投稿者、フォルダ、他のタブへ移動します。`/` で検索欄に移動します。

絞り込み中の条件は画面上部にまとまり、**リセット**で一括解除できます。

保存していないものは **ウェブで探す** から探せます。現在の絞り込み条件を各サイトの検索条件に変換して開きます。変換できない条件は、開く前に表示します。

### 4. 整理する

- **タグ** — 右クリックから「タグを編集」を選びます。「タグなし」で絞り込み、矢印キーで移動しながら続けてタグを付けられます。
- **タグを管理** — 右クリックから「タグを管理…」を選びます。名前の変更、統合、親タグ、孤児タグの削除、別名の設定ができます。
- **フォルダ** — 右クリックから「フォルダに追加…」を選びます。テーマや用途ごとに整理できます。
- **まとめて操作** — カード左上の ○ で複数選択し、タグ付け、フォルダ追加、グループ化、削除をまとめて実行します。
- **取り消し（`Ctrl+Z`）** — タグとフォルダの変更を1手ずつ戻せます。一括操作はトーストの「元に戻す」からも戻せます。削除した投稿はゴミ箱へ移動します。

### 5. 手元に残す

画面左下の **歯車（設定）** から操作します。

- ライブラリ全体を **ZIP** でエクスポート／インポート
- 別フォルダへの**定期バックアップ（ミラー）**
- **複数のライブラリ**の使い分け。別のフォルダを開いて切り替えます。元のライブラリは残ります。
- テーマ（ライト／ダーク）・表示言語

## 取得できないとき

本文、投稿者、日時、反応は、ブラウザが各プラットフォームの API から直接取得します。Hologram が利用者に代わってログインすることはありません。画面に表示されていても、API が情報を返さない投稿があります。

- **X** — 年齢制限付きの投稿と、鍵付きアカウントの投稿。匿名向けの API を使うため、ログイン状態は使いません。
- **Misskey / Mastodon** — フォロワー限定の投稿と、未ログインの API アクセスを無効にしたサーバー。
- **Bluesky / pixiv** — この制約はありません。pixiv は利用者のログイン状態を使います。

情報を取得できないときの動作は次のとおりです。

- **`Alt+S`** — スクリーンショットを保存し、画面の表示から情報を補います。数値は概数です。
- **その他の保存** — 指定した画像を保存します。本文や投稿者などは欠ける場合があります。
- 投稿情報も画像も取得できないときは保存しません。空の項目を残さないためです。

どの場合も保存したその場でお知らせします。

## プライバシー

保存先は利用者が選んだローカルフォルダです。Hologram のアカウントや中継サーバーはありません。外部通信は、投稿情報を取得するプラットフォームと、利用者が選んだ外部操作に限られます。詳しくは [PRIVACY.md](docs/PRIVACY.md) を参照してください。

### データの置き場所

- **ライブラリ**（画像＋メタデータ）: あなたが選んだ普通のフォルダ（既定は `~/Hologram/library`）
- **設定**: 各 OS 標準の設定ディレクトリ（Windows は `%APPDATA%\Hologram`）

どちらもアプリのインストール先の外にあります。アプリをアンインストールしても削除されません。すべて削除するには、この2つのフォルダを削除してください。
