この記録は、ゲートを一時的に緩和する前の状態を復元するために作成した。取得日時は 2026-08-12 である。復帰の追跡は #1104 で行う。

`main-ruleset-before.json` は既定ブランチに適用するルールセットの編集可能な項目だけを保存する。復帰時には、この値を基準にルールセットを更新する。取得時のルールセット ID は `20417382` である。

復帰後は、既定ブランチで次を確認する。

- プルリクエストが必須である。
- 削除と履歴を書き換える push が拒否される。
- `lint / typecheck / test` と `Electron harnesses / extension e2e` が必須チェックである。
- ワークフロー実行が有効で、アクションの利用範囲が `all` である。
